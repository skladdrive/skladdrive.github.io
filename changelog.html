Журнал версий

История обновлений, исправлений и заметок по версиям СкладDrive.

Версия 1.2.4 — 08.10.2026

  • В архиве теперь лежит готовая папка SkladDrive: распакуйте её в любое удобное место, заранее создавать папку вручную не нужно.
  • Обновление стало проще: новая версия распаковывается прямо в вашу рабочую папку. Оставшиеся от прежней версии файлы программа убирает сама, и старая версия больше не мешает работе.
  • Код компьютера теперь привязан к самому железу, а не к установке Windows. Раньше после переустановки системы код менялся и лицензию приходилось получать заново — теперь для лицензий, выданных начиная с этой версии, переустановка Windows больше не требует нового ключа.
  • Пробный период по той же причине больше не обнуляется при переустановке Windows.
  • Лицензии, купленные до этой версии, после переустановки системы по-прежнему потребуют один раз получить новый ключ.

Версия 1.2.3 — 07.10.2026

  • Исправлено появление второго товара при правке карточки, открытой из справочника: смена артикула, бренда или штрихкода больше не создаёт дубль и не оставляет устаревшую строку в справочнике.
  • Правка поля «Штрихкод» теперь заменяет штрихкод, а не добавляет второй. Второй штрихкод добавляется кнопкой «Штрихкоды».
  • Товар с несколькими штрихкодами показывается в справочнике одной строкой и находится по любому из кодов.
  • В поступлении по артикулу показывается список всех позиций с этим артикулом, даже если одна из них уже заведена на складе.
  • Восстановление из резервной копии работает, когда программа и данные находятся на разных дисках.
  • Сохранение карточки товара больше не прерывается ошибкой, если не удалось отправить данные в онлайн-справочник.
  • Понятные сообщения об ошибках вместо технического текста, в том числе при восстановлении, экспорте и операциях со складом.
  • Поиск по названию работает одинаково на складе и в справочнике, в любом регистре.

Версия 1.2.2 — 15.08.2026

  • Добавлены четыре независимых поста с отдельными досками записи.
  • Улучшена карточка работы: интервалы времени, несколько работ, справочники клиентов и автомобилей.
  • Обновлены интерактивные часы и выбор свободного времени.
  • Обновлены контекстные меню, работа с фотографиями и пиктограммы выбора даты и времени.

Версия 1.2.1 — 01.08.2026

  • Первый публичный релиз программы.
  • Добавлен подключаемый онлайн-справочник запчастей для пользователей с активной лицензией.
  • Локальные данные имеют приоритет: облачный поиск помогает только при отсутствии карточки на компьютере.
  • На доске работ появились интерактивные часы со свободными и занятыми интервалами записи.
